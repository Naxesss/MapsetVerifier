## 2.2 - 2026-10-29

The Ranking Criteria are now built into MV, and snapshots finally show what actually changed!

On top of that, 2.2 gives the whole app a cleaner, more consistent look by redesigning almost every page.

This is a beta, so expect some rough edges. Please report anything that looks off!

### Ranking Criteria

The osu! Ranking Criteria now live inside MV. Each check links to the rules and guidelines it covers, and we've reviewed them to make sure they point to the right ones.

A new Ranking Criteria page shows which rules checks cover, along with overall coverage statistics, so it's easy to see what MV checks for you and what still needs a manual look.

The Ranking Criteria are kept in sync with the osu! wiki. When a rule changes, we mark it as outdated until we review the linked checks again. The wiki's content usage permissions page is kept in sync too, and you can read it under Reference.

![ranking criteria](changelog/2.2/ranking-criteria.jpg)

### Snapshots

Snapshots have been reworked to make it much easier to see what changed between versions of a map:

- Timing changes are shown properly
- Related changes are grouped together instead of listed one by one
- Object changes are shown the way they look in-game
- Hitsound changes are now tracked
- You can compare against the full history, or pick your own start and end point
- Clicking a changed object opens it in the editor
- Values that osu!lazer and osu!stable only write differently, such as extra decimals or combo colours with an alpha, no longer show as changes

### A cleaner look

Every page now shares the same layout, spacing, tooltips and dropdowns. Switching between pages or beatmaps uses calmer transitions, and the Checks and Snapshots screens take up less space, leaving more room for what matters.

![checks page](changelog/2.2/checks-full.jpg)

We also reworked the difficulty picker. Every difficulty now has its own button under the beatmap header, in spread order, next to General. On the Checks page, each button shows that difficulty's status, so you can see right away which ones have problems or warnings. On the Snapshots page, they show which difficulties changed. Guest difficulties show the mapper's name above the difficulty.

![difficulty buttons](changelog/2.2/difficulty-buttons.jpg)

Hybrid sets show one game mode at a time, with a button for each mode at the end. Each mode button sums up the status of its difficulties, so nothing gets missed. osu!mania sets with more than one key mode are split per key mode or playstyle, such as 4K, 7K, 7K+1 or DP. Key counts above 9K are now read correctly too.

![osu!mania key modes](changelog/2.2/difficulty-key-modes.jpg)

Difficulty colours now also match how they look in osu!, check filtering is easier to use, and buttons you can't use right now are dimmed instead of hidden.

There's more than we can fit into a few screenshots, so if you have ideas for other visual upgrades or reworks, please share them with us!

### Overview

The Overview page has been redesigned to match the rest of the app. It now focuses on showing information about your mapset, and the Checks page handles judging.

The Objects tab is also much faster on bigger mapsets, and its timeline can now play the song so you can follow along with the objects.

### New checks

- **Broken stacks** (osu!): points out an object placed just off a stack, so the game doesn't stack it with the others
- **Content usage permissions**: points out songs from artists who don't allow, or only partly allow, their songs to be used in osu!, based on the osu! wiki. Disallowed artists are a problem, and artists with exceptions show their conditions
- **Image file format**: points out images whose file name says a different format than the image really is, such as a PNG saved as `.jpg`

### Fixes and improvements

- Difficulty names with extra words, like "Normal Dream", are now recognised as that difficulty level
- The hitsound consistency check now includes storyboarded hitsounds
- More unused hitsound files are detected, and circles no longer count as having a tail hitsound
- Fewer false "Unused timing lines" reports for sample and slider velocity changes that are needed
- Slider ticks are now timed the same way the game does it
- osu!catch: fixed false edge dash warnings, and a "Too high combo" made of a single slider is now only a minor issue that says so
- osu!mania: key mode markers like "[7K]" are no longer mistaken for guest names
- Reports, difficulty order and snapping comparisons are now the same every time you run the checks
- Fixed images sometimes failing to load, and the "Wrong snapping" check sometimes failing, while checks run
- Changes to a beatmap in osu!lazer now show up in MV right away
- MV uses less memory
- Song loading no longer hangs when a folder in your Songs library is corrupted
- The spectrogram no longer shows noise above an audio file's frequency cutoff, which could make low-quality audio look fine. The Average Peak Frequency is also more accurate now (thanks hongaaronc!)
- Fixed a few errors that could occur while loading audio and Overview resources
- Added a setting to choose how times are shown throughout the app (24-hour or 12-hour format)

Thanks to Hivie for a lot of the UI polish in this release, from the difficulty picker and check filtering to the faster Objects tab and its audio playback!
